Android launcher fix

The working Ninimum project contains:
- Platforms/Android/AndroidManifest.xml
- Platforms/Android/MainActivity.cs with MainLauncher = true
- Platforms/Android/MainApplication.cs

The Delivery project was missing MainActivity.cs and MainApplication.cs.
That caused:
  The "RunActivity" task was not given a value for the required parameter "ActivityName".

This package adds those files and keeps the Delivery icon configuration.

After replacing:
  dotnet clean
  rm -rf bin obj
Then uninstall Ninimum Delivery from the phone and run/build again.
